# לוגו MM — ייצוא

הלוגו נוצר מחדש בספטמבר 2026 בסגנון שמורן ביקשה: מונוגרמה **MM** בזהב,
קו דק עם מעוינים, **LAW OFFICE**, ומתחת **משפט פלילי**.

האותיות מומרות לנתיבים (outlines) ולא נשארות כטקסט, כך שהלוגו נראה זהה
בכל מקום גם בלי הגופן המקורי.

## גופנים וצבעים

- **MM** — Playfair Display 700
- **LAW OFFICE** — Cinzel 500, מרווח אותיות רחב
- **משפט פלילי** — Frank Ruhl Libre 500
- זהב `#C9A257` (מדורג מ-`#F2DCAE` עד `#9E7833`), נייבי `#0B2641`

## ליצירה מחדש

```
python tools/build-logo.py
```

הסקריפט מוריד את הגופנים (OFL) בהרצה הראשונה ובונה את כל חמשת קבצי ה-SVG.
לשינוי מרווח בין האותיות, גדלים או נוסח — הכול בפרמטרים בראש הסקריפט.

## הלוגו הקודם

`../logo-art-deco.svg` ושלושת קבצי ה-PNG שלידו הם הלוגו הראשון (מונוגרמה MZL
בסגנון ארט דקו, עם הכתובת "משרד עורכי דין וגישור"). נשמרו להיסטוריה; הם אינם
בשימוש באתר.
