## שתי הערות

**השורה בעברית בלוגו המלא** (`mzm-logo-full-art-deco.png`) מגיעה משחזור וקטורי
של קובץ תמונה, והאותיות בה יצאו מרווחות בצורה לא אחידה. בגלל זה באתר עצמו
"משרד עורכי דין וגישור" נכתב בטקסט חי ולא בתמונה. אם צריך את הלוגו המלא
לדפוס, כדאי לקבל מהמעצב/ת המקורי/ת את קובץ המקור.

**צבעים:** זהב `#C7AA7C` (וריאציות באתר: `#C9A257` / `#D7B16B` / `#B18B3A`),
נייבי `#0B2641`.
