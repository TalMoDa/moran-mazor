# לוגו MM — ייצוא

הלוגו של משרד עורכי דין מורן זילכה מזור: שתי אותיות **M** שזורות זו בזו, כשאזור
החפיפה בגוון זהב עמוק יותר כדי לקבל תחושת מתכת שזורה. סביבן מסגרת ארט-דקו
עם פינות חתוכות, קו כפול ומעוינים למעלה ולמטה. מתחת: **LAW OFFICE** ו**משפט פלילי**.

האותיות מומרות לנתיבים (outlines) ולא נשארות כטקסט, כך שהלוגו נראה זהה בכל
מקום גם בלי הגופן המקורי, וניתן להגדיל אותו לשילוט בלי איבוד איכות.

## גופנים וצבעים

- **MM** — Playfair Display 700, חפיפה 28%
- **LAW OFFICE** — Cinzel 500, מרווח אותיות רחב
- **משפט פלילי** — Frank Ruhl Libre 500
- זהב `#C9A257` (מדורג מ-`#F4E0B4` עד `#9C7530`), נייבי `#0B2641`

## ליצירה מחדש

```
python tools/build-logo.py
```

הסקריפט מוריד את הגופנים (OFL) בהרצה הראשונה ובונה את כל קבצי ה-SVG.
לשינוי חפיפה, שולי מסגרת, גדלים או נוסח — הכול בפרמטרים בראש הסקריפט.
